# Changelog

## 0.1.0

Initial public (unofficial) release.

- Chat with and manage local AI coding agents (Claude Code, Codex, GitHub
  Copilot, OpenCode, Pi) inside VS Code.
- Auto-opens the Paseo workspace matching the current folder, including the exact
  git worktree when a worktree directory is opened.
- Drag files from the Explorer or OS file manager into chat; hold **Shift** while
  dropping to insert them as `@`-mentions.
